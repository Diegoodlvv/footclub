Ce projet nommé footclub présente une application web permettant la gestion de joueurs de foot, d'équipes, de matchs et de membres de staff technique.
Ce projet a été réalisé individuellement par Diego De Oliveira. 

Les fonctionnalités présentes sur ce projet sont : 

- Ajout, modification et suppression de joueurs
  
- Ajout, modification et suppression d'équipes
  
- Ajout, modification et suppression d'équipes adverses
  
- Ajout, modification et suppression de membres du staff
  
- Ajout, modification et suppression de matchs

Etapes pour démarrer le projet : 

1 - Installer un serveur web sur votre pc (Xampp de préférence)
2 - S'assurer que votre dossier xampp contient une version de php supérieure a 8.2 
3 - Installer le dépot github (ZIP du projet) sur votre ordinateur personnel 
4 - Extraire le dossier de son ZIP et le déplacer dans C:/xampp/htdocs 
5 - Lancer phpMyAdmin (cliquer sur le bouton admin de la ligne mySql dans xampp)
6 - Créer une nouvelle base de données nommée footclub 
7 - Dans cette base de donnée, cliquer sur l'onglet importer, puis choisir un fichier 
8 - Choisissez le fichier footclub.sql dans votre dossier du projet 
9 - Sur le navigateur de votre choix, lancer votre projet en écrivant localhost/footclub/public dans la barre de recherche 
10 - Utiliser le projet à votre guise pour gérér le projet foot de votre choix !
